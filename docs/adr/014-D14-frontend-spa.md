# ADR-014: Kiến trúc Frontend

- **Trạng thái:** Đã chấp thuận (Accepted)
- **Ngày quyết định:** 2026-11-11
- **Phạm vi:** shop-support-agent

## Bối cảnh và Vấn đề
Cần đưa ra quyết định kiến trúc chuẩn xác cho kiến trúc frontend trong hệ thống shop-support-agent.

## Quyết định
React + Vite + TypeScript SPA với Tailwind CSS.

## Lý do và Đánh giá
Cần thẻ đề xuất tương tác, tải ảnh, bàn làm việc nhân viên; triển khai tĩnh gọn gàng.

## Hệ quả
Quyết định này được áp dụng xuyên suốt mã nguồn, bộ test và tài liệu hệ thống.
